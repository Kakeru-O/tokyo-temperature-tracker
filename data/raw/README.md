# Raw data (`data/raw/`)

このディレクトリには、気象庁「過去の気象データ」から取得したCSVを**そのまま**配置します（ADR-0003）。

取得方法と更新手順は [`docs/data.md`](../../docs/data.md) を参照してください。

ここは source-only です。分析や dbt の入力としては、`data/processed/` の整形済みCSVを使います。

※raw は基本的に **CP932(Shift_JIS)** を前提に読み込みます。取得・保存手順によって UTF-8 化されたCSVになる場合があるため、整形スクリプトでは CP932 で読めない場合に UTF-8 へフォールバックします。

## 置き方（例）
- 25 年ごとの分割ファイルをそのまま置きます
- 後続の取り込み処理（SQL/COPYやPython）で結合・正規化します

## ファイル形式（今回のCSV）
先頭にダウンロード時刻などが入り、ヘッダーが複数行あります。

- 1行目: `ダウンロードした時刻：YYYY/MM/DD HH:MM:SS`
- 2行目: 空行
- 3〜6行目: 複数行ヘッダー（地点名/項目名/品質情報/均質番号）
- 7行目以降: データ本体

データ本体の列（10列）:
1. `年月日`
2. `平均気温(℃)`（値）
3. `平均気温` の `品質情報`
4. `平均気温` の `均質番号`
5. `最高気温(℃)`（値）
6. `最高気温` の `品質情報`
7. `最高気温` の `均質番号`
8. `最低気温(℃)`（値）
9. `最低気温` の `品質情報`
10. `最低気温` の `均質番号`
